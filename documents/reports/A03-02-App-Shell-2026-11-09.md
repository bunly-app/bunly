## 2. Hành vi đã triển khai

| Phần | Hành vi thực tế |
|---|---|
| App shell | Hôm nay / Tra cứu / Sổ học / Tiến độ; mặc định Hôm nay. Header hồ sơ và logout dùng lại luồng có sẵn. Demo có nhãn riêng, connected có SyncBanner thật. |
| Điều hướng | IndexedStack giữ tab state, query, filter và scroll. Đổi tab đóng bàn phím. Chi tiết/hồ sơ push ở navigator cấp trên, không hiện navigation bar. Back trả đúng ngữ cảnh; back hệ thống từ tab phụ về Hôm nay. |
| Hôm nay | Mục tiêu từ profile; nhóm mẫu do user đánh dấu cần ôn/đang học; mở kho hoặc sổ học thật. Không gọi trạng thái “Cần ôn” là lịch đến hạn tự động. |
| Tra cứu | Tận dụng SearchGrammar/catalog metadata. Query/filter/saved filter, trạng thái nguồn/cache, loading/empty/error/retry; danh sách lazy, dropdown xếp dọc trên màn hẹp/chữ lớn. |
| Sổ học | Mẫu đã lưu trong catalog; tab ghi chú lấy mọi note đúng owner/backend, kể cả note thuộc mẫu chưa lưu. Mở chi tiết để sửa/xóa bằng use case cũ; cập nhật danh sách qua stream. Không render mọi note một lúc. |
| Tiến độ | Tổng hợp trạng thái fresh/learning/review/mastered trong catalog hiện có, hiển thị số mẫu đã bắt đầu; chạm trạng thái để xem các mẫu tương ứng. Ghi rõ self-assessment, chưa có dữ liệu accuracy bài luyện. |
| Đổi user | Navigator theo namespace/user reset shell/tab/query. Derived state không hiển thị kết quả cá nhân cũ khi tài khoản mới đang tải. Notes query vẫn lọc namespace + owner + deleted_at null. |
