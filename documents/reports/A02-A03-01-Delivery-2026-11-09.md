## 2. Quyết định contract cần review

- Source load metadata là snapshot domain, không state mutable của implementation. `source` là asset khi demo và remote khi connected; không suy thành verified Cloud.
- Span API dùng UTF-16 code units end-exclusive; có emoji fixture để kiểm tra surrogate boundaries.
- Request idempotency gồm user + request ID + fingerprint; retries không tạo thêm lượt; ledger/reservation/lease cần implementation riêng A05.
- Review canonical order v1 dùng server receipt rồi attempt UUID; client timestamp chỉ là metadata. Lịch offline là tạm và có thể dời sau sync. Đã cập nhật PRD để không giữ mô tả thời gian mơ hồ khác contract. Đây là đánh đổi cần Ánh/Vy review.
- Content draft có trạng thái pending_review, reviewed_by/reviewed_at null; 24 câu có đáp án nhưng distractor cần nâng chất lượng trước dùng cho người học.
